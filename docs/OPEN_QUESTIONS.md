# Open Questions

Status: `OPEN`

These are unresolved research questions, not a future feature list. A question
should move only when new evidence changes a decision or narrows the
uncertainty.

1. Does “Adaptive Engineering Control” have a mature corresponding term in
   existing research or industry practice?
2. Which internal designs are independently rediscovering existing Harness or
   agent-engineering research?
3. Which mechanisms should be owned by the Model, Runtime, Harness, ordinary
   Software Engineering, or Human authority?
4. Is a new Harness Framework actually necessary?
5. Does a Context Compiler need to be built, or are existing Runtime, Project,
   and Memory primitives sufficient for most of the problem?
6. How can Harness benefit and overhead be measured objectively?
7. How can a Harness avoid becoming a constraint as model capability improves?
8. Which historical mechanisms should be classified as
   `KEEP / SIMPLIFY / MOVE_TO_RUNTIME / MOVE_TO_MODEL / REMOVE`?
9. What is the actual implementation and completion status of the historical
   mechanisms?
10. Is there a residual gap that is both genuinely unresolved and worth
    building or experimentally testing?

## Evidence rule

Until a question is answered by a bounded, traceable investigation, its status
remains `UNKNOWN` or `OPEN`. Familiarity, an internal discussion, a
successful demo, or a single model-generated explanation is not sufficient
evidence.
