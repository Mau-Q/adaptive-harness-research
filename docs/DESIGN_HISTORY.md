## Reconstruction requirements

The order may need to be re-verified. Each phase must eventually be tied to
provenance such as an original conversation record, repository evidence,
commit, implementation plan, experiment, or explicit Human decision.

Do not:

- treat a discussed design as implemented;
- treat an implementation as adopted;
- treat a historical decision as current;
- treat a report or handoff as stronger than the evidence it points to;
- silently repair conflicts by choosing the most plausible version.

The reconstruction should explicitly record supersession, externalization,
weakening, and unresolved identity when those are present.
