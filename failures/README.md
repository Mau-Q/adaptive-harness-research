# Failure Patterns

Status: `EMPTY / NOT_STARTED`

This directory is reserved for curated, traceable, and appropriately
anonymized Agent/Harness failure patterns. The records should describe the
failure, context, evidence, impact, and what would falsify or weaken the
interpretation.

Possible future categories include:

- wrong trajectory;
- false completion;
- scope creep;
- control defined but not consumed;
- stale authority;
- historical applicability failure;
- unnecessary Human gate;
- over-governance;
- validation theater;
- Maker/Checker contamination;
- reinvention or prior-art blindness.

This bootstrap does not generate or import failure records from historical
chats.
